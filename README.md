Windows QA 0.62.85에 현재 개발 내용을 반영했습니다. 친구들도 모두 같은 버전을 새로 받아 접속하세요.

- 낙하 3m마다 체력 1칸이 줄고, 15m 이상은 즉사합니다. 3m 미만은 피해가 없습니다.
- 코스 밖 누적 5초, 코스 안에서 연속 3초면 초기화합니다.
- 현재 능력은 001~055입니다. 출발 + 무작위 맵 6개 + 결승, 맵 1/4 기준 부활을 사용합니다.
- 이전 개발 패치의 능력 변경·아이콘·획득 연출, 주먹·피격음, 숲속미로·결승선, 별도 게임 닉네임도 포함합니다.

설치본 EXE 또는 무설치 Windows ZIP을 받으세요. ZIP은 전체 압축을 풀고 게임 실행.cmd를 실행합니다. GitHub 자동 Source code 압축은 게임 실행 파일이 아닙니다. GPT·GitHub·Steam 계정은 필요하지 않습니다.

같은 LAN은 근처 방/7자리 코드로 접속합니다. 코드는 인터넷 중계·IP 익명화·비밀번호가 아닙니다. 다른 집·기기 통신 차단 환경은 별도 네트워크 설정이 필요하며 Steam 중계는 아직 없습니다. unsigned QA이므로 다른 PC의 SmartScreen/방화벽 경고가 사라졌다고 보장하지 않습니다. 게임이 방화벽·SmartScreen·네트워크 프로필을 자동 변경하지 않습니다.

검증 범위: 선택한 게임 검사 6종, 정확 PCK의 낙하 경계·실제 캡슐 자유 낙하·호스트 피해/사망 동기화, 실제 Windows EXE 두 개의 코드 입장/스냅샷, 설치·제거를 확인했습니다. 한 PC 기능 검사이며 실제 두 PC/WAN·사람 조작/청음·장시간·일반 FPS 승인과 구분합니다. 기존 호스트 지연·MTU/대형 ENet 누락은 OPEN 상태입니다.
