## 이번 갱신

기존 다운로드120 이후 완료한 수정과 검증된137 소스를 반영했습니다.

- 급경사 굽은 내리막·화물 점프 계단을 제거했습니다. 19개 후보 중 서로 다른8개에 출발·결승을 더합니다.
- 부표 해변을 추가했습니다. 여러 명이 서면 가라앉는 부표, 기러기와 파도를 통과합니다.
- 숲속미로의 공유 시드 미로·무작위 출구, 모래사막 탐색 지형, 상자적재장의 개별 상자 파괴·낙하, 컨베이어의 옆 통로 차단 등 완료한 맵 수정을 포함합니다.
- 벼락산 지형·연결부·번개 배치와 코스 밖 장식 지형 정리를 포함합니다.

맵별 크기 확대는 아직 진행 중입니다. 모든 맵이 단독2~3분 목표를 달성했다는 뜻은 아닙니다.

## 설치와 업데이트

새 설치 파일을 받아 실행하면 기존 설치 위치에서 업데이트합니다. 닉네임·설정·기존 바로가기 실행 옵션은 유지합니다. 일반판과 크리에이터판은 별도로 설치·업데이트합니다. 예전 폴더 이름의 버전 숫자가 남아 있어도 게임 왼쪽 아래 표시가137인지 확인하세요.

업데이트할 게임은 먼저 직접 종료하세요. 설치 프로그램은 실행 중인 게임을 종료하지 않으며 사용 중인 파일의 덮어쓰기를 거부합니다. 같은 설치본을 다시 실행하면 복구 설치합니다. 무설치 게임 ZIP은 제공하지 않습니다.

크리에이터는 일반판과 같은 메인메뉴에서 시작합니다. 플레이 → 크리에이터 연습에서 능력·NPC·맵을 고릅니다. F2 편집, F3 시점 전환, F1 조작 방법을 사용하세요.

## 검증 범위

실제 일반137EXE의 메뉴와 호스트/참가자 경주, 정확PCK의19후보·37저장변형·삭제자원 부재, 설치된 두 채널의 화면을 확인했습니다. 구버전120에서 업데이트, 동일버전 복구, 파일잠금 거부, 다운그레이드 거부, 신규 설치·제거를 실제 설치 파일로 확인했습니다. 크리에이터137의 완료된 원자료는 같은 런타임·불변파일 SHA를 확인해 재사용했습니다.

한 PC의 기능 검사입니다. 기존 MTU/큰 스냅샷 누락·호스트 지연은 미해결 항목으로 남아 있습니다. 저사양 FPS, 다른 PC/WAN, Steam 실계정, 사람 청음·장시간 전체 조합은 별도 검증이 필요합니다. 무궁화 구호의 최종 음색도 사용자 검토가 남아 있습니다.

현재 QA는 코드서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다. 공식 배포와 SHA를 확인하세요. LAN 방 코드/검색은 인터넷 중계·비밀번호·IP 익명화 기능이 아닙니다. 다른 회선에서는 VPN 또는 방장 UDP 설정이 필요합니다.
