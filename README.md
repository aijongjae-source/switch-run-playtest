## 설치와 업데이트

새 설치 파일을 내려받아 **실행하면 기존 설치 위치에 업데이트**합니다. 닉네임·설정과 바로가기 실행 옵션은 유지됩니다. 같은 버전을 다시 실행하면 복구 설치합니다. 일반판과 크리에이터판은 서로 별도로 관리합니다.

업데이트할 게임은 먼저 직접 종료하세요. 설치 파일은 사용 중인 파일을 덮어쓰거나 게임을 강제 종료하지 않습니다. 자동 다운로드 서비스는 설치하지 않습니다.

예전 폴더 이름에 `0.62.95` 같은 숫자가 남아 있어도 위치를 유지하면서 내용은 최신 버전으로 갱신됩니다. 게임 왼쪽 아래 버전을 확인하세요. 예전 버전별 설치가 여러 개라면 가장 최신 설치를 이어 사용하며 다른 옛 설치는 자동 삭제하지 않습니다.

배포는 설치판만 제공합니다. 별도 무설치 게임 ZIP은 제공하지 않습니다. 관리자 권한이나 Steam/GitHub 계정 없이 설치하고 혼자 또는 LAN으로 시험할 수 있습니다. 현재 파일은 코드서명이 없는 개발 중 QA이며 Windows 경고가 나타날 수 있습니다. 보안 기능을 끄지 말고 공식 배포와 SHA를 확인하세요.

## 이번 변경

- 벼락산 본 구간의 실제 폭을 4.6m로 통일하고 입구·출구만 이웃 맵에 완만하게 연결했습니다.
- 겹치고 찢어져 보이던 바닥·암벽을 다시 저장하고 공중 장식 37개를 제거했습니다.
- 번개가 여러 방향과 안개 속에서도 선명하게 보이도록 바꿨습니다. 기존 낙뢰 간격·경고 시간·피해 반경·동시 수는 유지합니다.
- 최신 실행 아이콘, 프로필·조작법·능력 설명 등 현재 검증된 수정이 설치판에 포함됩니다.
- 다시 설치할 때 버전마다 별도 앱이 늘어나지 않도록 고정 설치 식별자를 사용합니다.

크리에이터는 기본 메인메뉴에서 시작합니다. 플레이 → 크리에이터 연습에서 능력·NPC·맵을 선택하고 F2로 편집, F3로 시점을 바꿉니다. 일반 경주는 원래 출발·사망 추첨 규칙을 사용합니다.

## 검증 범위

실제 EXE·정확한 PCK·설치된 게임 화면을 확인했습니다. 일반/크리에이터 각각 구버전 업데이트·재설치·파일 잠금 거부·설치·제거 25개 조건을 검사했습니다. 벼락산 중립 능력의 피해·회피·보호막·권한·복귀·1/8 AI 통과를 확인했습니다.

한 PC의 기능 검사이며 저사양 FPS·물리적으로 다른 PC/WAN·Steam 실계정·사람 청음·장시간 전체 조합을 보증하지 않습니다. 기존 MTU 초과/큰 스냅샷 누락과 호스트 지연은 미해결입니다. 낙뢰 수를 늘리는 후보는 이 부하 때문에 제외했습니다. 014 주시 능력의 경고 정지와 보호막 등 원래 능력 효과는 유지합니다.

같은 네트워크의 방 코드/검색은 인터넷 중계·암호·IP 익명화 기능이 아닙니다. 다른 회선은 VPN 또는 방장 UDP 설정이 필요합니다. 연결 안내를 확인하세요.

필수 저작자·라이선스 고지는 설치 폴더의 `THIRD_PARTY_NOTICES.txt`와 `licenses`에 있습니다.
