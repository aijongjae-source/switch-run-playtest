새 설치 파일을 실행하면 기존 설치 위치에 업데이트합니다. 닉네임·설정·바로가기 실행 옵션은 유지합니다. 같은 버전은 복구 설치이며 일반판과 크리에이터는 별도로 업데이트합니다. 설치할 게임은 직접 종료하세요. 설치 프로그램이 게임을 강제 종료하지 않습니다. 무설치 ZIP이나 자동 다운로드 기능은 제공하지 않습니다.

0.62.160 이후의 수정과 새 능력055 머리가 반짝!·056 텔레포트,능력 장기 보유 규칙,크리에이터 NPC 반복 동작·상시 퀵창/F2 전체 설정을 포함합니다. 숲속미로의 닫힌 석벽,시장·외나무다리와 맵별 이탈 경계,낙석·통나무 빈도 및 회전원판 협곡의 넓은 가로·대각선·갈림길 경로도 반영했습니다. 회전원판은 크기·회전 속도·원심력이 서로 다릅니다.

현재 능력은001~056이며 동시에 하나를 보유합니다. 출발·사망 때 무작위 추첨하며 최근 두 능력을 제외합니다. 일반 경주의3분 보유 교체와150초 예고,010·013·027 예외 및 소진 후20초 교체를 구분합니다. 현재17후보에서8개를 뽑고 출발·결승을 더합니다.42.195km는 코스 환산 표시입니다.

크리에이터 연습에서는 퀵창이 항상 보입니다. Alt를 누른 채 클릭하고 놓으면 시점 조작으로 돌아갑니다. F2는 전체 설정을 바로 열고,F3시점 전환·F6무적/분리 비행은 해당 연습에서만 동작합니다. NPC는 선택한 동작을 반복하며,퀵창 사용은 세계를 멈추거나 느리게 하지 않습니다.

일반 Windows 실행본의8명/원래AI7 경주와 실제PCK의17후보·35저장장면·256선택시드,검증된Creator285의 불변payload,실제160→285 설치·복구·제거를 범위 한정 확인했습니다. 이것은 전게임·성능 통과를 뜻하지 않습니다. 기존 큰 ENet 패킷 경고와 일부 단발 스냅샷 누락은 미해결이며,다른PC/WAN·호스트렉·저사양·장시간·사람 조작/청음은 별도 검증이 필요합니다.

모든 참가자는 같은285 버전을 사용하세요. 같은LAN은 방 검색/7자리 코드,다른 네트워크는 별도VPN 또는 호스트UDP설정이 필요합니다. 코드는 인터넷 중계나 비밀번호가 아닙니다. 방화벽 설정은 게임의 명시적 허용 절차를 따르며 설치가 자동으로 변경하지 않습니다.

서명되지 않은 QA이므로 Windows SmartScreen 경고가 나올 수 있습니다. 보안 설정을 끄지 말고 공식 배포처와 SHA256을 확인하세요. 외부 저작물 고지와 라이선스는 설치 폴더의 THIRD_PARTY_NOTICES.txt 및 licenses에 있습니다.
