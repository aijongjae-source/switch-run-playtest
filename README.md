# SWITCH RUN! — Windows 멀티플레이 QA

**최신0.62.57-qa1 · Windows10/11 64비트 · 최대8명 · 계정 불필요**

**[설치본 EXE](https://github.com/aijongjae-source/switch-run-playtest/releases/download/v0.62.57-qa1/SwitchRun-0.62.57-qa1-Windows.exe)** · **[무설치 ZIP](https://github.com/aijongjae-source/switch-run-playtest/releases/download/v0.62.57-qa1/SwitchRun-0.62.57-qa1-Windows.zip)** · [SHA-256](https://github.com/aijongjae-source/switch-run-playtest/releases/download/v0.62.57-qa1/SwitchRun-0.62.57-qa1-Windows.sha256)

Steam 등록 전 계정 없는 Windows QA입니다. 참가자는 모두0.62.57-qa1을 사용하세요.

- 같은 공유기:방 만들기에서7자리 코드를 복사하고,친구는 방 참가의 근처 방 또는 코드로 접속합니다.
- 코드 검색은 로컬LAN용이며 인터넷 중계/IP익명성/방비밀번호가 아닙니다. 공유기·PC방의 기기간 통신 차단은 우회하지 못합니다. 다른집은 현재 VPN/직접주소 방식입니다. Steam연동은 아직 없습니다.
- 접속 도움말에서 현재 실행파일 경로를 복사하고 Windows 허용 앱 설정을 열 수 있습니다. 방화벽/백신/SmartScreen/네트워크프로필을 자동변경하지 않습니다. 현재 네트워크에 맞는 허용 여부는 각PC에서 선택해야 합니다.
- unsigned QA의 SmartScreen창은 계속 나타날 수 있습니다. 포함된 안내와SHA를 확인하세요. 정식서명이나 무경고보장은 없습니다.
- 기존 체력/능력/낙석주의35m길/사망후퇴/20맵·45추첨능력/게임 ENet프로토콜은 유지합니다.

EXE설치 또는 ZIP전체를 풀고 게임 실행.cmd를 실행하세요. 계정은 필요하지 않습니다. 방장도 게임을 켜 둬야 하며 진행 중 참가·호스트 이전은 지원하지 않습니다.

실제 새 WindowsEXE끼리 한PC UDP코드검색→ENet입장→2유저+1AI경주와 discovery정리,네이티브화면,실제설치·제거/ZIP해시를 확인했습니다. 실제옆PC문제의단일원인·물리LANbroadcast/방화벽승인/SmartScreen·WAN/VPN·Steam·사람청음/수시간/FPS는미검증입니다. 기존큰ENet패킷MTU경고·누락과호스트지연은남아있습니다. 전체렉해결이나출시완성판정이아닙니다.

이전056qa1을 포함한 모든 역사배포는 보존합니다. 개발소스는 별도 비공개입니다. 자세한 접속법은 QA-GUIDE.ko.txt를 확인하세요.
