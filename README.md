# SWITCH RUN! — Windows 다운로드

최신 다운로드는 **0.62.312-qa1**입니다. Windows 10/11 64비트에서 설치할 수 있습니다.

- [일반 게임 설치](https://github.com/aijongjae-source/switch-run-playtest/releases/latest/download/SwitchRun-Windows.exe)
- [크리에이터 설치](https://github.com/aijongjae-source/switch-run-playtest/releases/latest/download/SwitchRun-Creator-Windows.exe)
- [배포 페이지와 SHA256](https://github.com/aijongjae-source/switch-run-playtest/releases/latest)
- [설치·접속·조작 안내](QA-GUIDE.ko.txt)

게임을 종료한 뒤 새 설치 파일을 실행하면 기존 위치에 업데이트합니다. 닉네임·설정·바로가기 실행 옵션은 유지됩니다. 같은 버전을 다시 설치하면 복구 설치가 되며 일반판과 크리에이터판은 각각 업데이트합니다. 함께 플레이할 때는 모두 같은 **0.62.312** 게임 버전을 사용하세요.

일반 경주는 고속도로를 포함한 18개 후보 중 8개와 출발·결승을 더한 10구간입니다. 능력은 001~056이며 일반 경주의 장기 보유 교체는 생존 2분, 예고는 1분 30초입니다. 잠금 능력의 20초 대기와 010·013·027 예외는 따로 적용됩니다. 크리에이터 연습에서 F2는 전체 설정을 열며, Alt를 누르는 동안 상시 NPC 퀵창을 클릭할 수 있습니다.

0.62.312는 상자창고에서 멀리 있는 상자·울타리의 타격 계산과 시한폭탄 전달 대상의 불필요한 벽 검사를 줄였습니다. 폭탄 첫 표시 끊김과 일부 멀티플레이 패킷 누락은 남아 있습니다. 실측 범위와 설치 검증은 배포 페이지에 표시합니다.

서명되지 않은 QA 설치본은 Windows 보안 경고가 나올 수 있습니다. 공식 배포 주소와 SHA256을 확인하세요. 저작물 고지와 라이선스는 설치 폴더의 THIRD_PARTY_NOTICES.txt 및 licenses에서 확인할 수 있습니다.
