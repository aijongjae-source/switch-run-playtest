새 설치 파일을 실행하면 기존 설치 위치에 업데이트합니다. 닉네임·설정·바로가기 실행 옵션은 유지됩니다. 같은 버전 재설치는 복구 설치입니다. 자동 다운로드 기능은 없으며 실행 중인 설치본은 직접 종료한 뒤 업데이트하세요. 일반판과 크리에이터는 별도로 설치합니다. 무설치 ZIP은 제공하지 않습니다.

이번 갱신은 기존137 다운로드판에 후속160까지의 패치를 반영합니다. 꾸미기 처리 정리와 기본 의상, 화면 안내, 005 똥의 첫 미끄러짐 소모·20초 제거를 포함합니다. 삭제된 맵의 원본 옛 실행기와 번호가 바뀐 원본 실행기만 비실행 백업으로 옮기며, 수정한 파일은 보존합니다.

현재17개 후보 중8개를 선택하고 출발·결승을 더합니다. 모든 맵이2~3분 규모로 확대된 상태는 아닙니다.42.195km는 코스 환산 표시이고 충돌·이동·피해는 실제 월드 단위입니다. 능력001~055, 출발·사망 시 추첨과 개인별 최근2개 제외를 사용하며 전원20초 교체는 없습니다.

크리에이터의 플레이 → 크리에이터 연습/F2에서 능력·맵·NPC를 선택합니다. F3시점 전환, F6무적·분리 비행은 해당 연습에서만 동작합니다. 일반 온라인 플레이에 치트를 적용하지 않습니다.

한PC에서 실제 일반EXE8명 경주·현행 맵 목록/제거자원·005 접촉 제거, 검증된 로컬Creator160 재사용, 실제 구137→160 설치·복구·제거 범위를 확인한 QA입니다. 전게임·성능 통과를 뜻하지 않습니다. 기존 ENet 큰 패킷 경고와 일부 snapshot 누락은 미해결이며, 호스트렉·저사양 무끊김·실제 다른PC/WAN·Steam 실계정·장시간·사람청음은 보장하지 않습니다.

LAN방 코드는 인터넷 중계·비밀번호가 아닙니다. 같은LAN은 방 검색/코드, 다른 네트워크는 별도VPN 또는 호스트UDP설정이 필요합니다. 방화벽 설정은 게임의 명시적 허용 절차를 따르며 자동 변경하지 않습니다.

현재 서명되지 않은 QA이므로 Windows SmartScreen 경고가 계속 나올 수 있습니다. 보안 경고 제거를 보장하지 않습니다. 배포 페이지의 SHA256과 공식 배포처를 확인하세요.
