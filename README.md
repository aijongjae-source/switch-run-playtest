# SWITCH RUN! — Windows 다운로드

- [최신 일반판 설치 파일 받기](https://github.com/aijongjae-source/switch-run-playtest/releases/download/v0.62.327-qa1/SwitchRun-0.62.327-qa1-Windows.exe)
- [최신 일반판 배포 페이지와 SHA256](https://github.com/aijongjae-source/switch-run-playtest/releases/tag/v0.62.327-qa1)
- [설치·접속·조작 안내](QA-GUIDE.ko.txt)

게임을 종료한 뒤 새 설치 파일을 실행하면 기존 일반판을 업데이트합니다. 닉네임·설정·바로가기 실행 옵션은 유지됩니다. 함께 플레이할 때는 모두 같은 **0.62.327** 게임 버전을 사용하세요. 크리에이터판은 별도 배포 채널이며 위 링크의 기존 공개 버전은 312입니다.

327 일반판에는 시장 운반/낙하물, 부표와 파도/갈매기, 100m 상자 적재장, 회전 원판 지름길, 결승 관중 음향, 겨울 체력 처리의 복구된 6건 수정을 포함했습니다. 원본 Windows 실행 파일의 실제 8인 로비와 일반 8인 연습 경주를 확인했고, 공개 설치 파일을 비로그인 상태로 끝까지 내려받아 SHA256을 대조했습니다.

일부 엄격 단일 snapshot 검사와 MTU 경고는 남아 있습니다. 이번 배포를 전체 네트워크·물리 WAN·FPS·장시간 플레이·사람 청음 검증으로 해석하지 마세요. 상세 검증 범위는 최신 배포 페이지에 있습니다.

서명되지 않은 QA 설치본은 Windows 보안 경고가 나올 수 있습니다. 공식 배포 주소와 SHA256을 확인하세요. 저작물 고지와 라이선스는 설치 폴더의 THIRD_PARTY_NOTICES.txt 및 licenses에서 확인할 수 있습니다. 이 공개 저장소에는 다운로드 안내와 설치 파일만 올리며 개발 소스는 공개하지 않습니다.
