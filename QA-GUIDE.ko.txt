SWITCH RUN! 0.62.88-qa1 — Windows 멀티플레이 다운로드

시작하기
EXE 설치본을 실행하고 바탕화면의 SWITCH RUN! QA를 실행하세요.
압축본은 전체 압축을 푼 뒤 게임 실행.cmd를 실행하세요. EXE만 따로 옮기면 안 됩니다.
Windows 10/11 64비트용입니다. GPT, GitHub, Steam 계정이나 게임 구매가 필요하지 않습니다.
별도 웹 버전과 연결되지 않습니다. 모두 같은 Windows QA 버전을 사용하세요.

혼자 하기
플레이 → 혼자 달리기 → 참가 인원과 AI 성향 → 로비 만들기 → 경주 시작.
인원 1명은 혼자 연습, 2~8명은 나와 AI가 함께 달립니다.

친구와 하기 — 같은 와이파이/공유기
게임을 켜면 방을 만들기 전부터 Windows LAN 설정을 확인합니다. 방장·참가자 화면 모두 ‘LAN 연결 설정’을 사용할 수 있습니다.
허용 규칙이 없으면 ‘LAN 연결 설정 → 이 게임 LAN 허용’을 누르고 Windows 관리자 권한 창을 확인하세요.
현재 실행 파일의 UDP 통신만 같은 네트워크(LocalSubnet)에서 허용합니다. 개인·공용 프로필에 적용하며 방화벽 전체나 네트워크 분류는 바꾸지 않습니다.
방 검색 응답은 임시 UDP 포트로 오므로 이 앱의 임시 응답 포트도 포함합니다. 다른 앱·인터넷 전체에 대한 허용은 아닙니다.
방장: 플레이 → 방 만들기 → 인원/AI 선택 → 방 만들기. 출발선 로비에서 기다립니다.
방장: 왼쪽 위 7자리 방 코드를 확인하고 ‘코드 복사’로 친구에게 전달합니다.
친구: 플레이 → 방 참가. ‘같은 네트워크의 방’에서 친구 이름을 누르거나 방 코드를 붙여넣고 참가합니다.
친구: 준비 완료 → 방장이 경주 시작. 사람과 AI를 합쳐 최대8명입니다.
방 코드는 같은 네트워크의 방을 찾는 기능입니다. 공개 인터넷에서 주소를 감추는 중계·암호화·비밀번호가 아닙니다.
다른 집이나 단말 간 통신을 차단한 공유기/PC방에서는 코드만으로 연결되지 않습니다.
경주 시작 뒤 참가와 호스트 이전은 지원하지 않습니다. 방장이 게임을 계속 켜 두어야 합니다.

Windows에서 막힌 경우
‘Windows의 PC 보호’는 정식서명 전 QA 파일의 SmartScreen 경고입니다. 공식릴리스와 SHA를 확인하고 신뢰하는 경우에만 추가 정보 → 실행으로 진행합니다.
현재 QA는 코드서명이 없으며,이 경고가 계속 나타날 수 있습니다. 백신/SmartScreen을 끄는 기능은 넣지 않았습니다.
‘Windows 방화벽’ 경고는 게임 통신 허용이며 SmartScreen과 별개입니다. 방 생성 시에만 Windows 알림이 나타날 수 있고, 알림이 꺼진 공용 프로필에서는 창이 안 뜰 수도 있습니다.
게임 시작 때의 검사는 읽기 전용입니다. ‘이 게임 LAN 허용’을 직접 선택하기 전에는 관리자 권한 요청이나 허용 규칙 추가를 하지 않습니다.
Windows가 공용 네트워크로 분류했다면 개인 네트워크만 체크한 허용으로는 부족할 수 있습니다. 신뢰하는 집의 네트워크 분류와 허용 대상이 맞는지 확인하세요.
자동 허용을 취소했거나 관리자 정책 때문에 실패하면 ‘직접 허용 앱 설정 열기’를 누르세요. Windows의 허용 앱 설정을 열고 현재 실행 파일 경로를 복사합니다.
설정 변경 → 다른 앱 허용 → 찾아보기에서 복사한 게임 실행 파일을 추가합니다. 설치본은 버전마다 경로가 다를 수 있습니다.
PC방의 관리자 정책·게스트 와이파이의 기기 간 차단은 관리자에게 문의하세요. 방화벽 전체를 끄지 마세요.
게임 통신은 기본 UDP7777,방 검색은 UDP27777이며 참가자의 검색 응답은 임시 UDP 포트를 사용합니다.
허용 규칙이 있어도 관리자 차단 정책·공유기 기기 격리·버전 불일치까지 해결됐다는 뜻은 아닙니다. 버전이나 설치 경로가 바뀌면 새 실행 파일에 다시 허용해야 합니다.
현재 컴퓨터만 방장을 할 수 없고 상대가 방장일 때는 접속된다면 현재 컴퓨터의 인바운드 허용·공용 프로필·명시적 차단을 먼저 확인하세요.

친구와 하기 — 서로 다른 집, Radmin VPN 사용
Radmin VPN 공식 다운로드/안내: https://www.radmin-vpn.com/help/
모두 Radmin VPN을 설치하고 실행합니다. 원격 제어용 Radmin Server는 필요 없습니다.
한 명이 네트워크 이름과 비밀번호로 비공개 네트워크를 만들고, 친구들은 같은 네트워크에 참가합니다.
게임 방장은 위의 방 만들기를 진행합니다. 방 코드는 인터넷 중계가 아니므로 VPN에서는 방장 VPN 주소로 직접 접속할 수 있습니다.
친구들은 Radmin VPN 창의 방장 가상 IP 뒤에 :7777을 붙여 방 코드 입력란에 직접 입력합니다. ‘직접 주소 / 설정’에서 포트도 바꿀 수 있습니다.
예: 26.x.x.x:7777 (예시를 그대로 입력하지 말고 방장의 실제 주소를 사용하세요.)
게임의 코드 복사는 VPN IP를 대신하지 않습니다. VPN 창에서 방장 주소를 복사해 직접 입력하세요.
공유기 포트 개방 대신 가상 LAN을 사용하는 방식입니다. VPN의 설치/동작은 별도 프로그램의 범위입니다.

친구와 하기 — VPN 없이 직접 인터넷 IP 접속
방장이 공유기에서 UDP 7777을 게임 실행 PC의 내부 IPv4로 전달해야 합니다.
친구는 방장의 공인 IPv4:7777로 참가합니다. 192.168.x.x는 다른 집에서 사용할 수 없습니다.
이중 공유기나 통신사 CGNAT 환경은 포트 개방만으로 연결되지 않을 수 있습니다.
설정이 어려우면 위의 가상 LAN 방식을 사용하세요. 현재 자동 매칭이나 Steam·인터넷 방 코드 중계는 없습니다. 같은 LAN의 7자리 방 코드와 구분하세요.

연결되지 않으면
모두 같은 QA 버전인지, 경주 시작 전에 로비로 들어갔는지 확인합니다.
방장 주소와 포트, 로비 최대 인원, VPN 네트워크 참가 여부를 확인합니다.
Windows 방화벽에서 해당 SwitchRun.exe의 게임 통신을 허용합니다. 방화벽 전체를 끄지 마세요.
VPN 어댑터가 공용 네트워크로 잡혔다면 해당 어댑터에서도 게임 통신 허용이 필요할 수 있습니다.
공유기의 TCP만 개방하면 안 됩니다. 이 게임은 UDP를 사용합니다.
방장 종료 시 경기도 끊깁니다. 진행 중 참가/호스트 이전은 지원하지 않습니다.

현재 경주 규칙
능력은 001~055 중 출발 때 받고, 사망한 선수만 다시 받습니다. 055의 미사용 보호는 예외입니다.
한 경기는 출발 + 무작위 맵 6개 + 결승입니다. 능력을 얻으면 화면 중앙에서 표시된 뒤 아래 카드로 이동합니다.
체력은 10칸입니다. 낙하 거리 3m마다 1칸(3/6/9/12m에서 1/2/3/4칸)이 줄고, 15m 이상은 즉사합니다.
3m 미만의 일반 점프는 낙하 피해가 없습니다. 헤르메스의 조종 중 하강과 자유 낙하는 구분합니다.
코스 아래 15m 이상 추락도 즉사합니다. 코스 밖 시간은 누적 5초이며, 안에서 연속 3초면 누적값이 초기화됩니다.
사망한 맵을 1/4 이상 진행했으면 현재 맵 입구, 그 전이면 이전 맵 입구로 부활합니다. 첫 맵은 출발점입니다.
일반 주먹은 체력 1칸을 줄이고 고개·상체를 돌리며, 상대를 뒤로 밀지 않습니다. Q 밀기·잡기와 능력의 힘은 별도입니다.
추가 피해 없이 5초가 지나면 체력 1칸이 회복됩니다.
게임 닉네임은 Steam 계정과 별도로 설정할 수 있고, 기본 이름이 중복되면 숫자로 구분합니다.

조작
W/S/A/D 이동 · 마우스 시점 · Space 점프
왼쪽 클릭 공격 · 오른쪽 클릭 누르는 동안 뒤돌아보기
E 누르는 동안 잡기 · Q 밀기 · Shift 능력 사용
Esc 메뉴 · F1 조작법 · Alt+Enter 전체 화면/창 모드
물체에 끼었다면 Esc → 긴급탈출. 이동/피격/낙하 중에는 사용할 수 없습니다.

테스트와 제보
맵 테스트 폴더에서 특정 맵을 고를 수 있습니다. 각 실행기에서 AI 인원을 바꿀 수 있습니다.
QA 제보 양식.txt에 상황을 적어 개발자에게 보내 주세요. 로그는 자동으로 전송되지 않습니다.
렉은 설정 → 화면 → 가벼움으로 비교해 보고, 인원/맵/능력/게임 경과 시간을 함께 적어 주세요.
이 테스트 배포는 아직 개발 중이며 실제 외부 PC/회선과 장시간 플레이 검증을 위한 것입니다.

삭제와 저장
설치본은 Windows 설치된 앱에서 해당 SWITCH RUN! QA 버전을 제거할 수 있습니다.
압축본은 압축을 푼 게임 폴더를 지우면 됩니다.
꾸미기/설정은 이 PC의 Godot 사용자 폴더에 별도 보관되며 제거 시 자동 삭제하지 않습니다.
미인증 IP 멀티의 닉네임은 직접 입력한 이름입니다. Steam 계정 인증으로 보증된 이름은 아닙니다.

체력
내 체력은 화면 왼쪽 아래 10칸, 상대 체력은 머리 위 이름표에 연속 막대로 표시합니다.
주먹에 맞으면 1칸 감소하며, 추가 공격 없이 5초가 지나면 1칸 회복합니다. 이후에도 5초마다 1칸씩 회복합니다.
체력이 줄면 초록에서 노랑을 거쳐 진한 빨강으로 변합니다. 상대 체력은 방장의 판정으로 동기화됩니다.

0.62.57 능력 변경 규칙
출발할 때 능력을 하나 받고, 사망한 선수만 이전과 다른 능력을 새로 뽑습니다.
살아 있는 선수는 능력과 남은 사용 횟수를 유지하며20초 자동 교체는 없습니다.
033 능력 제거의20초 중립 시간과 각 능력의 지속시간은 그대로입니다.

0.62.57에 포함된 최근 변경
가까운 상대의 이름·체력 표시, 연속 상대 체력바, 진한 저체력 색과 짧은 피격·주먹 반응을 적용했습니다.
사망 정보는 왼쪽 위 순위 위로 옮기고 능력 아이콘·사망 시 교체 안내 문구를 제거했습니다.
낙석주의 도로는 35m이며 길옆 기둥을 제거하고 초원 연결부를 수정했습니다. 자연돌 피격 후퇴는 같은 입력 검사에서 약 절반입니다.
빙판 장애물 통로·채석장 오르막·협곡 외나무다리·수로 물길 커브·뱀처럼 굽은 능선·절벽 벼랑길은 맵 자체를 제거했습니다.
남은 맵 후보는 20종이며 한 경기에서 14개를 선택합니다. 별도 외나무협곡은 남아 있습니다.
능력 표기는 001~100이며 능력 없음은 100입니다. 일반 경기 추첨 풀은 기존 001~045의 45종을 유지합니다.
사망 후퇴는 기본 속도 15~30초 분량으로 줄였으며 출발선 제한과 안전 복귀 검색을 유지합니다.
이전 다운로드 버전과는 함께 접속하지 말고 참가자 전원이 0.62.85-qa1을 사용하세요.

검증 범위와 남은 문제
실제 Windows 실행본 화면·한 PC의 호스트/참가자 기능 검사를 수행합니다. 서로 다른 PC·VPN/WAN·Steam 실계정은 미검증입니다.
호스트 지연과 큰 ENet 패킷 누락 문제는 일부 남아 있습니다. 이번 배포를 전체 랙 해결로 보증하지 않습니다.
낙석 피격 순간 큰 돌이 카메라를 잠깐 가리거나 겹치는 현상, 일부 지형의 재질·조명 차이는 남아 있습니다.
모든 맵/능력 조합·사람 조작·청음·저사양 PC 장시간 플레이는 추가 QA가 필요합니다.
